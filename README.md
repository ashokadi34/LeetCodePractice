# LeetCode Practice

A collection of solutions to LeetCode problems, organized to practice problem-solving skills and strengthen Data Structures and Algorithms (DSA) fundamentals.

The repository includes **Easy, Medium, and Hard** problems, with solutions written primarily in **Java**.

## Topics Covered

- Arrays and Strings
- Hashing
- Linked Lists
- Stacks and Queues
- Two Pointers and Sliding Window
- Binary Search and Sorting
- Trees and Binary Search Trees
- Recursion and Backtracking
- Graphs
- Dynamic Programming
- Other problem-solving patterns

## Project Structure

Solutions are added as practice progresses. The folder structure and topic coverage may grow over time.

## Difficulty Levels

Problems are practiced across all three difficulty levels:

- **Easy** – Build fundamentals and understand core concepts.
- **Medium** – Improve problem-solving skills and apply common patterns.
- **Hard** – Practice advanced algorithms and optimize solutions.

## Tech Stack

- Java
- Maven
- Data Structures and Algorithms

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/ashokadi34/LeetCodePractice.git
   ```
2. Open the project in your preferred Java IDE.
3. Choose a problem and review its solution.
4. Run the solution or its tests from your IDE.

## Goal

Practice consistently, understand the logic behind each solution, and improve algorithmic thinking and coding skills for technical interviews.
